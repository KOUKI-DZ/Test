# Camera Verification Demo (Arabic)

واجهة عربية بتأثيرات حركة توضيحية عامة، ومعاينة للصورة وموافقة صريحة قبل إرسالها إلى Telegram. هذا مشروع تجريبي مستقل وليس خدمة Cloudflare أو CAPTCHA حقيقية.

## الملفات
- `public/index.html` — واجهة متجاوبة مع شرح متحرك لخطوات التصوير.
- `server.js` — خادم Node.js ومعالجة EXIF وإرسال الصورة إلى Telegram.
- `Dockerfile` — يثبت ExifTool ويشغل الخادم.
- `render.yaml` — إعداد خدمة Render.

## إعداد توكن Telegram
**الموصى به:** افتح Render > الخدمة > Environment، وأضف: `TELEGRAM_BOT_TOKEN` (قيمة توكن البوت) و`TELEGRAM_CHAT_ID` (معرّف المحادثة). معرّف المحادثة مضبوط افتراضيًا على `7669414161`.

إذا كنت تريد إدخال توكن تجريبي داخل الكود، افتح `server.js` وابحث عن السطر:

```js
const BOT_TOKEN = process.env.TELEGRAM_BOT_TOKEN || 'PASTE_YOUR_TEST_BOT_TOKEN_HERE';
```

استبدل `PASTE_YOUR_TEST_BOT_TOKEN_HERE` بالتوكن التجريبي. لا ترفع توكن حقيقي إلى مستودع GitHub عام؛ من يستطيع قراءة الملف يستطيع استخدام البوت. إذا سبق نشر التوكن، ألغِه من BotFather وأنشئ واحدًا جديدًا. متغير Render يتقدم على القيمة المكتوبة في الملف.

## النشر على Render
1. ارفع جميع الملفات والمجلد `public` إلى مستودع GitHub.
2. في Render اختر **New > Web Service** ثم اربط المستودع.
3. اختر **Docker** كبيئة التشغيل.
4. أضف `TELEGRAM_BOT_TOKEN` في Environment، أو استخدم موضع التوكن التجريبي داخل `server.js` كما سبق.
5. انشر وافتح رابط الخدمة. مسار `/health` لاختبار استجابة الخادم.

## تشغيل محلي
يتطلب Node.js 20+ وExifTool. بعد ضبط المتغيرات شغّل `node server.js` ثم افتح `http://localhost:3000`.

## الخصوصية والحدود
- الكاميرا تعمل بعد إذن المستخدم فقط. لا تُرسل الصورة إلا بعد التقاطها، ووضع علامة الموافقة، والضغط على زر الإرسال.
- لا تستخدم الواجهة لجمع صور الآخرين دون علمهم وموافقتهم.
- قد لا تحتوي صورة الكاميرا على EXIF أو GPS؛ لا يمكن استخراج بيانات غير موجودة.
- لم يتم اختبار إرسال حقيقي إلى Telegram؛ تحقق من إعدادات البوت والمحادثة بعد النشر.
- واجهة الكاميرا تحتاج HTTPS على الموقع المستضاف.
