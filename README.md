# Photo Check — مشروع التقاط صورة بموافقة واضحة

صفحة عربية متجاوبة لالتقاط صورة بالكاميرا الأمامية أو الخلفية، معاينتها، ثم إرسالها إلى بوت تيليجرام **بعد موافقة صريحة**. بعد نجاح الإرسال ينتقل الزائر إلى رابط الوجهة المحدد داخل `index.html`.

## الملفات
- `index.html`: الواجهة والكاميرا والمعاينة.
- `server.js`: خادم Node.js يرسل الصورة إلى Telegram Bot API.
- `Dockerfile`: إعداد النشر على Render.
- `render.yaml`: إعداد متغيرات البيئة.

## النشر على Render
1. ارفع هذه الملفات جميعًا إلى جذر مستودع GitHub، بحيث يكون `index.html` بجانب `server.js` و`Dockerfile`.
2. أنشئ Web Service من المستودع أو استخدم Blueprint.
3. في Render → Environment أضف:
   - `TELEGRAM_BOT_TOKEN`: رمز البوت (سرّي، لا تضعه في GitHub).
   - `TELEGRAM_CHAT_ID`: معرّف المحادثة أو المجموعة التي أُضيف إليها البوت.
4. ابدأ النشر وافتح رابط Render باستخدام HTTPS؛ الكاميرا لا تعمل عادةً على HTTP غير الآمن.
5. جرّب بنفسك: افتح الكاميرا، التقط صورة، راجع المعاينة، وافق على الإرسال، ثم تأكد من وصولها إلى تيليجرام.

## ملاحظات الخصوصية
- الصفحة لا تنتحل هوية Cloudflare ولا تدّعي أنها تحقق رسمي من الروبوتات.
- توضح الصفحة قبل فتح الكاميرا أن الصورة مطلوبة في تدفق هذا الموقع، وأن إرسالها إلى تيليجرام يحتاج إلى موافقة منفصلة.
- لا تُجمع إحداثيات GPS أو معلومات موقع المستخدم.
- الصورة الملتقطة عبر Canvas لا تحتفظ عادةً ببيانات EXIF الأصلية.
- لا تحفظ الصور على القرص في الخادم؛ تمر في الذاكرة ثم تُرسل إلى Telegram.
- احتفظ برمز البوت في متغير بيئة فقط. إذا سبق نشر الرمز علنًا، ألغِه وأنشئ رمزًا جديدًا عبر BotFather.
